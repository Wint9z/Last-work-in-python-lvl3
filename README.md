# Last-work-in-python-lvl3



##  Цель проекта

Создать удобный инструмент профориентации, который:

* помогает определиться с будущей профессией
* предлагает понятные шаги для старта
* делает процесс выбора карьеры простым и интересным

---



###  Основные возможности:

* Тест на определение интересов
* Подбор профессий
* Краткое описание профессий
* Рекомендации по развитию

###  В планах:

* Персонализированные рекомендации
* Roadmap (пошаговый план обучения)
* Сравнение профессий
* Интеграция с курсами

---

##  Как это работает

1. Пользователь проходит тест
2. Бот собирает данные (интересы, цели и т.д.)
3. Алгоритм сопоставляет ответы с базой профессий
4. Пользователь получает рекомендации
